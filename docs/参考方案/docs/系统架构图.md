## 二、任务执行流程图（巡航 + 拍照）

```mermaid
flowchart LR
    START([开始]) --> INIT["初始化状态机<br/>加载 49 个导航点"]
    INIT --> LOOP{"遍历导航点<br/>i = 1..49"}
    LOOP --> GOTO["GoToPose<br/>发送 /move_base goal"]
    GOTO --> RESULT{"导航结果?"}
    RESULT -->|"succeeded(状态码3)"| CHECK{"是否为拍照点?<br/>(ro1/ro2/chepai)"}
    RESULT -->|"aborted"| ABORT([任务中止<br/>TASK_ABORTED])
    CHECK -->|"否"| NEXT["进入下一个导航点<br/>i = i + 1"]
    CHECK -->|"是"| WAIT["等待 2s 刷新相机"]
    WAIT --> PHOTO["TakePhotoState<br/>调用 /take_photo 服务"]
    PHOTO --> SAVE["photo_server 保存 JPG<br/>(时间戳去重防掉帧)"]
    SAVE --> PHOTO_RESULT{"拍照结果?"}
    PHOTO_RESULT -->|"success"| NEXT
    PHOTO_RESULT -->|"失败"| ABORT
    NEXT --> LOOP
    LOOP -->|"i > 49"| DONE([完成<br/>TASK_DONE])
```

## 三、识别流水线（拍照 → 检测 → 识别）

```mermaid
flowchart LR
    IMG["照片 JPG<br/>photo/photo1, photo2"] --> ENH["图像预处理<br/>亮度增强 / CLAHE"]
    ENH --> DET["YOLOv5 目标检测<br/>shequ.pt 社区模型"]
    DET -->|"目标框"| OUT1["结果图 PNG<br/>output/results_*"]
    DET -->|"文字区域"| OCR["EasyOCR 字符识别"]
    OCR -->|"车牌号/文字"| OUT2["终端输出<br/>车牌/文字 + 置信度"]
```
