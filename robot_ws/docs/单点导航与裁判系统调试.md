### 4. S2：定义保存当前实际位姿的命令

复制整段，在 S2 定义一次 `save_point`。它将当前 `map → base_footprint` 的位置和朝向写回三份路线中存在的同名点，每次自动备份，保留任务、相机和分支配置。

```bash
save_point() {
python3 - "$1" <<'PY'
from pathlib import Path
from datetime import datetime
import sys, math, shutil
import yaml, rospy, tf2_ros
from tf.transformations import euler_from_quaternion
workspace = Path('/home/mowen/workspace/Smart-Community/robot_ws')
sys.path.insert(0, str(workspace / 'src/community_mission/scripts'))
from rules import validate_route
name = sys.argv[1]
config = workspace / 'src/community_mission/config'
updates = []
for filename in ('route.yaml', 'route_clear.yaml', 'route_blocked.yaml'):
    path = config / filename
    route = yaml.safe_load(path.read_text())
    points = [p for p in route['points'] if p['id'] == name]
    if points:
        updates.append((path, route, points[0]))
if not updates:
    raise SystemExit('未找到航点：' + name)
rospy.init_node('save_adjusted_waypoint', anonymous=True, disable_signals=True)
buffer = tf2_ros.Buffer()
listener = tf2_ros.TransformListener(buffer)
transform = buffer.lookup_transform('map', 'base_footprint', rospy.Time(0), rospy.Duration(5))
age = (rospy.Time.now() - transform.header.stamp).to_sec()
if not -0.1 <= age <= 1.0:
    raise SystemExit('TF 已过期或时间异常，未写入坐标')
t, q = transform.transform.translation, transform.transform.rotation
yaw = euler_from_quaternion([q.x, q.y, q.z, q.w])[2]
if not all(math.isfinite(v) for v in (t.x, t.y, yaw)):
    raise SystemExit('位姿无效，未写入坐标')
pose = dict(x=round(t.x, 4), y=round(t.y, 4), yaw=round(yaw, 4))
for path, route, point in updates:
    point.update(pose)
    validate_route(route)
backup = Path.home() / 'maps/route_backups' / datetime.now().strftime('%Y%m%d_%H%M%S_%f')
backup.mkdir(parents=True)
for path, route, point in updates:
    shutil.copy2(path, backup / path.name)
for path, route, point in updates:
    temporary = path.with_suffix('.yaml.tmp')
    temporary.write_text(yaml.safe_dump(route, allow_unicode=True, sort_keys=False))
    temporary.replace(path)
    print('已保存', path.name, name, pose)
print('原路线备份：', backup)
rospy.signal_shutdown('坐标保存完成')
PY
}
```

例如车身已微调到 `wp_06` 的理想位置，执行：

```bash
save_point wp_06
```

绕行点同理：

```bash
save_point blocked_wp_08
```

`yaw` 为弧度。保存的是小车当前实际位姿；不要通过移动 RViz 的定位箭头代替车身微调。该命令会重排 YAML 格式，但只更新同名航点的 `x/y/yaw`，其他字段保持原值。

## 四、最后跑全程（S2）

1. 退出单项测试、单点导航和键盘控制，S1 保持运行。
2. 将小车摆回起点，在 RViz 确认定位与实际位置、朝向一致。
3. 在裁判大屏清理此前单项测试数据，确认当前队伍。
4. 将任务物料、红绿灯和指示牌准备好，执行：

```bash
roslaunch community_mission mission.launch judge_enabled:=true judge_url:=http://192.168.31.83:8080 judge_team:=麦当劳薯条三重奏
```

完整任务由 `wp_05` 的实际检测自动选择 clear/blocked 分支；依次执行识别、测温、仪表、车牌、垃圾和停车区统计。`wp_35` 定点拍照后直接前往 `wp_37`，最终在 `wp_39` 结束。通过摆放指示牌分别验证两种分支。

正常整轮不要加 `single_waypoint`、`task_only:=true`、`navigation_only:=true` 或 `skip_traffic_light:=true`。正式比赛每轮 5 分钟，现场调试窗口与比赛计时分开记录；当前程序没有全程 300 秒截止控制。

## 五、结果与异常停止

每轮以 S2 打印的 `[输出目录]` 为准，结果在 `~/.ros/community/<run_id>/`：`mission_results.json`、`mission.log`、`judge_reports.jsonl` 和 `photo/`。任务显示成功后还应确认 `[裁判上报成功]` 以及大屏最新图片；仪表 `SKIPPED` 或有效空结果都需要单独核对。

需要立即制动时使用实际急停；先在 S2 按 Ctrl+C 停止巡检，再在已加载环境的 S3 取消导航目标：

```bash
rostopic pub -1 /move_base/cancel actionlib_msgs/GoalID '{}'
```

停止其他运动控制程序后发送零速度：

```bash
rostopic pub -1 /cmd_vel geometry_msgs/Twist '{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}'
```

中断后重新启动完整巡检会从起点开始。正常收工顺序：退出 S2 任务 → Ctrl+C 退出 S1 基础系统 → 关闭自行启动的裁判进程。
